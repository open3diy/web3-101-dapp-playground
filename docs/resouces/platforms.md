
# Recursos para desarrolladores Web3: plataformas

Recursos útiles de plataformas para el desarrollo de smart contracts y DApps, incluyendo herramientas, documentación, proveedores de infraestructura y fuentes de datos recomendadas.

## Alchemy y Alchemy Sandbox

[Alchemy](https://docs.alchemy.com/docs) es un servicio en la nube que funciona como API entre la DApp y el smart contract. Ofrece servicios adicionales como webhooks, historial de transacciones, monitoreo y análisis de datos en tiempo real. Permite a los desarrolladores interactuar con blockchains de forma sencilla y eficiente, sin necesidad de gestionar nodos propios.

Ideal para crear un MVP (Producto mínimo viable), permite acelerar el desarrollo de aplicaciones Web3. Es una solución intermedia entre web2 y web3, incluyendo además [Alchemy Smart Wallets](https://www.alchemy.com/smart-wallets) que permite integrar acceso estilo web2 mediante account abstraction, transacciones gasless, etc. Esta solución facilita la incorporación de usuarios tradicionales al ecosistema blockchain, eliminando la necesidad de gestionar claves privadas o pagar comisiones por transacción. Además, Alchemy proporciona documentación detallada y ejemplos para desarrolladores que deseen implementar wallets inteligentes en sus aplicaciones

Alchemy ofrece un [Sandbox](https://sandbox.alchemy.com/) para invocar métodos JSON-RPC y explorar datos en vivo sin ejecutar un nodo local. Es útil para inspeccionar bloques, transacciones y el estado de contratos.

## Google Cloud Web3

[Google Cloud](https://cloud.google.com/application/web3/) con un enfoque parecido a Alchemy para acercar la web3, ofrece APIs o recursos y un servicio Blockchain, incluido recursos para diseñar, desplegar y probar aplicaciones descentralizadas.

Es interesante por [`faucet`](https://cloud.google.com/application/web3/faucet) o servicio de entrega de tokens de testnet para redes como Ethereum, Polygon y otras.

Como valoración, se puede decir que Alchemy es sin duda la solución más completa, funcional y eficiente, pero puedes utilizar recursos de Google Cloud Web3.

## Infura

[Infura](https://infura.io/) es una plataforma que proporciona infraestructura escalable para aplicaciones Web3, permitiendo a los desarrolladores conectarse a redes blockchain sin necesidad de operar nodos propios. Infura ofrece una capa de API y servicios que facilitan la integración de aplicaciones con Ethereum, IPFS y otras redes.

Infura es ampliamente utilizada por [MetaMask](https://metamask.io/), y sus creadores han desarrollado el [MetaMask SDK](https://developer.metamask.io/mm-sdk), que permite integrar funcionalidades de wallet en aplicaciones web y móviles.

Como recurso, Infura dispone de un [faucet para testnets](https://support.infura.io/blockchain-networks/testnets/using-the-testnet-faucet?utm_source=chatgpt.com), útil para obtener tokens de prueba en redes como Ethereum Goerli, Sepolia y otras.
