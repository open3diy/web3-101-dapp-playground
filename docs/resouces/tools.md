# Recursos para desarrolladores Web3: herramientas

A continuación se presenta un resumen de herramientas típicas utilizadas en el desarrollo de smart contracts y aplicaciones descentralizadas (dApps):

## Metamask

<https://metamask.io>

Metamask es una cartera de navegador y aplicación móvil que actúa como proveedor Web3: gestiona cuentas, firma transacciones y permite conectar dApps de forma sencilla.

Características principales:

- Gestión de cuentas y frases semilla (seed phrase).
- Cambio entre redes (Mainnet, redes de prueba como Sepolia/Goerli o redes personalizadas mediante RPC).
- Integración con hardware wallets (Ledger, Trezor).
- Firma de transacciones y mensajes, y permisos granulares para dApps.
- Funcionalidades de intercambio y compra de tokens (según región).

Buenas prácticas de seguridad:

- Nunca compartas tu seed phrase ni claves privadas.
- Verifica la URL y permisos que solicita la dApp antes de aprobar.
- Usa hardware wallets para fondos importantes.
- Prueba en redes de prueba y faucets antes de operar en Mainnet.

## Remix IDE

<https://remix.ethereum.org/#lang=en>.

Entorno de desarrollo en línea para escribir, compilar y desplegar smart contracts en Solidity.
